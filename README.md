## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/Shikha18Sahu/shikha-portfolio.git
```

### 2. Navigate into the project folder

```bash
cd shikha-portfolio
```

### 3. Open in browser

Simply open `index.html` in your browser:

```bash
open index.html
```

Or use the **Live Server** extension in VS Code for the best development experience.

## 🌍 Deployment

This site is deployed using **GitHub Pages**.

To deploy your own version:
1. Push your code to a GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Click **Save** — your site will be live at `https://<your-username>.github.io/<repo-name>`
